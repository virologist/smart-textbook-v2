# 使用指南 · smart-textbook-v2

> 从零到一章可用教材的完整操作路径。

---

## 1. 准备工作区

工作区 = 你的教材项目根目录（本包**不含**教材实例，实例在你的工作区里）。

```
<工作区>/
├── 00-教材规则/textbook_rules.yaml      ← 教材层规则（继承自基因层）
├── 章节/ch01/                            ← 章节层
│   ├── chapter_rules.yaml                ← 章节层规则（继承自教材层）
│   ├── gaps.md                           ← 缺口台账
│   ├── figure-registry.md                ← 图表登记表
│   ├── retrieval/INDEX.md                ← 检索索引（渐进式加载入口）
│   ├── logs/run_log.jsonl                ← 章节级日志
│   └── draft.md                          ← 正文
└── 03-运行状态/run_log.jsonl             ← 项目级日志
```

**目录契约**：`章节/{ch##}/`、`00-教材规则/`、`03-运行状态/`、`retrieval/`、`logs/`。命名规范见 `references/file-naming.md`。

---

## 2. 接入本包

```bash
export STT_WORKSPACE=/path/to/your/workspace
```

所有校验脚本都读这个环境变量定位被检对象；不设时默认指向包根（跑包内自检）。

## 3. 定制教材层规则

### 3.1 看继承链解析结果

```bash
python3 scripts/resolve_rules.py 章节/ch01 --emit
```

输出三段式差异报告：
- **继承**：来自基因层/教材层的既定值
- **变异**：教材层或章节层显式设定
- **待确认**：`_derived` 衍生块（联网检索衍生、附证据、待用户确认）

### 3.2 在教材层定制

教材层 `textbook_rules.yaml` 继承基因层。**只写你要改的字段**：

```yaml
inherits_from: "<包内>/references/rule-engine/base_rules.yaml"

depth_level: associate        # 学段（vocational/associate/bachelor/graduate）
word_target: 34000
word_tolerance: "+-10%"
min_figures: 8
min_questions: 16
sizheng_mode: "润物无声"

knowledge_scope:               # 学科专用值只在此层与章节层出现
  core: [ ... ]
  trigger_patterns: [ ... ]
```

**不可覆写**的字段（`inherit_only` / `fixed`）写在教材层覆写会被 `validate_rules.py` V1 拦下。

### 3.3 联网检索衍生（derive 态）

若某字段值想由检索衍生（如「本教材的术语表从某权威源拉取」），写入 `_derived` 块并附证据：

```yaml
_derived:
  terminology_table:
    value: { ... }
    derived_from: "检索任务 id / 批次号"
    evidence: "https://... 或 PMID:..."
```

**未确认的衍生值不并入最终规则**，但会出现在差异报告的「待确认」段——不静默生效、不静默丢弃。确认后迁入 `_local_overrides`（成为 override 态）。

## 4. 校验与门禁

```bash
# 规则层
python3 scripts/resolve_rules.py --selftest          # 解析 + 幂等 + provenance
python3 scripts/validate_rules.py --all              # V1-V7
python3 scripts/validate_rules.py --strict           # warning 升级为 error

# 缺口闭环
python3 scripts/check_gap_flow.py --all
python3 scripts/check_gap_flow.py 章节/ch01 --final   # 终稿清洁（残留标签必须 0）

# 图表
python3 scripts/check_figures.py --all
python3 scripts/check_figures.py 章节/ch01 --reconcile  # 摸排未登记图
python3 scripts/check_figures.py 章节/ch01 --renumber   # 重编号建议（dry-run）

# 通用门禁（35 判据）
python3 scripts/gates/g1_state_phase.py
python3 scripts/gates/g2_quality_citation.py
python3 scripts/gates/g3_figure_naming.py
python3 scripts/gates/g4_rules_files.py
python3 scripts/gates/g5_flow_health.py

# 日志
python3 scripts/check_log_schema.py --all
python3 scripts/check_tool_degradation.py --all       # 工具失败必须有 DEGRADE 记录

# 包契约（包维护者用）
python3 scripts/check_manifest.py
```

**退出码语义统一**：`0` 通过 · `1` 违规 · `2` 用法错误。**门禁以退出码为准**，不接受自评。

## 5. 日常流程

```
① 定规则      resolve_rules.py --emit → 差异报告 → 用户确认
② 拆缺口      教学设计产出数据需求 → 主编排审批（3-10）→ 台账登记
③ 检索        检索专员并行检索 → 产物落 retrieval/ + 建 INDEX
④ 回填        撰写师按编号标签回填 + 证据锚
⑤ 核验        审查官逐条核对台账 + 四轮审查
⑥ 图表        判型 → ipynb → 美学自检 ≤5 → 编号图注 → 登记
⑦ 交付        终稿清洁（残留标签=0）+ 门禁全绿
```

## 6. 常见问题

| 现象 | 原因 | 处置 |
|---|---|---|
| `validate_rules` 报「越权覆写」 | 章节层改了 `inherit_only`/`fixed` 字段 | 改回继承，或把字段改成 `override` 类型（需改基因层注册表） |
| `resolve_rules` 报「继承链断裂」 | `inherits_from` 相对路径不可达 | 改为相对教材根的可达路径（4 级） |
| `check_gap_flow` 报 G4「条目数不符」 | 检索产物新增未入 INDEX | 补 INDEX 条目（四字段齐全） |
| `check_figures` 报 F2「缺号」 | 图号跳号 | 跑 `--renumber` 出映射，人工确认后执行 |
| 工具调用失败但没报错 | 缺 DEGRADE 日志 | 写 `check_tool_degradation.py` 要求的降级记录（`fallback_from`/`fallback_to`） |
| 校验器「误报」教材专用值 | 通用层混入了学科内容 | 移到教材层/章节层；`check_manifest.py` M11 会持续拦 |
