# file-naming.md — 文件命名规范（单一权威源）

> **版本**: v1.0 | **日期**: 2026-11-02 | **维护**: B2 规则继承引擎批次（架构设计 §5.1 B2「目录/命名规范单一化」）
> **性质**: 本文件是文件命名规范的**唯一权威源**（SSOT）。
> `03-路由与命名.md` §4 与 `06-文件治理协议.md` §0 的原命名规范内容已收编至本文件，
> 两处改为指针引用（2026-11-02 起，双处维护即违规）。
> **红线 P-2**: 本文件为通用层文件，不含任何教材专用值，示例一律用 `{{placeholder}}` 占位。

## 1. 正式标准（所有层级通用）

> **格式**：`[序号]-[中文概述内容].md`
> **适用**：所有层级（系统规则层 / 教材层 / 章节层）正式文件。

```
[序号]-[中文概述内容].md
```

| 示例 | 说明 |
|------|------|
| `01-项目日志.md` | 顶层索引文件 |
| `03-{{domain_glossary}}.md` | 按序排列的参考标准 |
| `01-{{topic_keys}}-检索摘要.md` | 章节内检索摘要 |

## 2. 命名约束

- **禁止空格**（用 `-` 替代）
- **禁止超过 50 字符**
- **允许中英混排缩写**（如 `ch01-{{domain_example}}.md`）
- **禁止日期前缀**（如 `20260415-xxx`）；日期后缀用 `YYYYMMDD` 仅在导出文件名中允许
- 新建文件名必须在当前章节 `chapter_rules.yaml` 的 `allowed_files` 中注册

## 3. §4.X 编号段规范

> **原则**: 编号段决定文件类型，同一段内文件具有相同性质
> **来源**: 抽象层（`00-系统规则/`）定义，教材层继承

| 编号段 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 00-09 | System | 系统规则层（基础层规范与索引） | `00-索引.md`、`01-状态机.md`、`02-编写标准.md` |
| 10-19 | Rule / Guide / Track | 教材编写核心规则 | `11-教材规则.yaml`、`13-编写标准.md` |
| 20-29 | Rule（扩展） | 教材层扩展规则 | (预留) |
| 30-39 | Track | 项目元数据 | `31-项目日志.md`、`32-项目进度.md` |
| 40-49 | Input | 任务摄入 | `41-{{intake_digest}}.md`、`42-{{converted}}/` |
| 50-59 | Tool | 工具配置 | `chapter-scaffold.yaml` |
| 60-69 | Orphan | 归档/模板 | `99-archive/` |
| 70-99 | Reserved | 未来扩展 | (预留) |

**命名格式规则**：
- Rule 层：`NN-Rule-中文描述.yaml` 或 `NN-中文描述.yaml`
- Guide 层：`NN-Guide-中文描述.md` 或 `NN-中文描述.md`
- Track 层：`NN-Track-中文描述.md` 或 `NN-中文描述.md`
- Input 层：`NN-Input-中文描述.md` 或 `NN-中文描述.md`
- 孤儿层：无编号前缀，语义命名

**教材层命名原则**：教材层文件名应与抽象层源文件命名保持一致；镜像继承文件使用相同编号，扩展文件使用新编号段。

## 4. Stage 标签规范（收编自 06-文件治理协议 §0）

> **设计原则**: 从文件名即可辨识用途，语义优先，序号保留维持引用兼容性
> **格式**: `NN-Stage语义描述.ext` | Stage 标签 = 文件类型的阶段角色

| Stage 标签 | 含义 | 包含类型 |
|------------|------|---------|
| `Rule-` | 规则/标准/规范 | 编排约束、质量参数、检索配置、排版规范 |
| `Guide-` | 指南/手册/参考 | 写作指南、术语表、统稿指南、样张说明 |
| `Track-` | 追踪/元数据 | 日志、进度、经验记录、错误模式、任务概要 |
| `Input-` | 素材/输入 | 原始素材、消化摘要、转换材料 |
| `Tool-` | 工具配置 | scaffold、模板等 |
| `Orphan-` | 孤儿/归档 | 模板文件、废弃文件、参考文件 |

**通用层文件命名**（`00-系统规则/`）：使用通用描述，如 `03-状态机.md`（Stage 隐含）
**教材层文件命名**（`tb_*/00-系统规则/`）：**强制使用 Stage 前缀**，如 `13-编写标准.md`

**编号分配规则**：
- Rule/Guide: 10-19（教材编写规则）
- Track: 30-39（项目元数据）
- Input: 40-49（任务摄入）
- Tool: 无固定编号
- Orphan: 无编号，仅保留语义描述

## 4.5 协议固定文件名（豁免）

下列文件名由**协议约定**（章节层 `allowed_files` 白名单），不是自由命名对象——**豁免编号与中文概述要求**：

`chapter_rules.yaml` · `chapter_spec.md` · `chapter_design.md` · `write_plan.md` · `draft.md`（及 `draft_v{N}.md` / `draft_proofread.md` / `draft_export_clean.md`）· `handoff.md` / `handoff.json` · `data_spec.yaml` · `gaps.md` · `figure-registry.md` · `visual_plan.md` · `illustration_plan.md` · `assets.md` · `progress.md` · `INDEX.md` · `README.md` · `proofread_feedback.csv` · `runtime_state.json` · `textbook_rules.yaml` · `project_registry.yaml`

> 适用范围：本规范仅约束**系统规则层**与**教材/章节层正式文件**；`skills/` `agents/` `scripts/` `templates/` 的文件名由各自代码生态约定（Skill 名=目录名、Agent MD 名=agentName），不适用本规范。

## 5. 特殊文件命名

| 文件类型 | 命名规则 | 示例 |
|---------|---------|------|
| 审查报告 | `ch{XX}_round{N}_{YYYYMMDD}.md` | `ch02_round1_20260416.md` |
| 题库文件 | `ch{XX}_qbank.md` | `ch02_qbank.md` |
| 导出成品 | `YYYYMMDD-{项目名}-{版本}.{ext}` | `20260416-{{project}}-v1.0.docx` |
| ipynb 图表 | `{章号}-{图号}_{描述}.ipynb` | `02-01_{{figure_desc}}.ipynb` |
| 草稿快照 | `draft_v{N}.md` | `draft_v1.md` |
